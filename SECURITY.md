# Security scope

This is an educational local lab. No production deployments or real accounts are supported. Do not submit credentials, seeds, private keys, or personal data in public issues.

For a suspected vulnerability, use the repository's private vulnerability reporting feature if the owner has enabled it. If it is unavailable, ask the owner for a private reporting route without posting exploit details or sensitive material. No monitored security mailbox or response-time guarantee is claimed.

Keep secrets and runtime data out of Git. If credentials or TOTP seeds were disclosed, rotate/revoke the credentials and re-enroll affected factors; deleting a file from the current branch does not undo exposure. Review existing history and external copies before publication.
